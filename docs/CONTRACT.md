# Shared implementation contract
React + TypeScript Vite frontend; Express Node24 built-in SQLite backend. All data synthetic, five illustrative countries SG/MY/TH/ID/VN full names, Product A/B/C. No real external integrations.
API helper src/api.ts fetches /api. All GETs JSON. Backend port3001. UI uses role header X-Role (Sales, Finance, Quality, BU Head, Admin), demo role switching explicitly not authentication. GET /api/bootstrap returns {customers,products,orders,requests,audit}; /api/analytics returns analytics (analytics owner defines and informs others); /api/graph returns {nodes,edges} (graph can derive from bootstrap instead).
Customer {id,name,country,identifier,email,aliases:string[]}; Product {id,name,category}; Order {id,customerId,productId,country,month:'2026-01',quantity,signal:'confirmed'|'enquiry'|'setup'}; Request {id,type:'Customer'|'Vendor'|'Item'|'Cost Center',name,country,identifier,email,details,requester,status:'Pending'|'Clarification'|'Rejected'|'Approved',stage:string,approvals:string[],createdAt,deadline,priority:number,duplicateOverride?:string}; Audit {id,requestId,action,actor,timestamp,details}.
POST /api/duplicates body {name,identifier,email,type} returns {matches:[{customer:Customer,score:number,evidence:string[]}]}; score 0-100 heuristic not probability. POST /api/requests body request fields + duplicateOverride; validates and enforces unresolved high matches. POST /api/requests/:id/action {action:'approve'|'reject'|'clarify'|'resubmit',note} header X-Role. GET /api/requests/:id/sap returns SAP-shaped simulated JSON only when approved. POST /api/simulate {sourceId,targetId} returns {before:{customerCount,sourceQuantity,targetQuantity},after:{customerCount,targetQuantity},affectedOrders,totalQuantity,explanation}; simulation does not mutate. POST /api/reset resets synthetic fixture.
Component exports: default Requests({onInvestigate?:(id:string)=>void}); default Intelligence({initialCustomerId?:string}); default Analytics(); each owns its CSS file. App handles navigation, sidebar, global theme, loading errors. Global classes available: panel, page-header, eyebrow, button, button secondary, badge, badge warning, badge success, muted, stat-grid, stat-card, field, empty-state. Colors CSS variables --ink #20393f --muted #76868a --teal #087f75 --border #e1e8e6 --canvas #f4f7f6. White panels 12px radius. Main content max width 1500. All controls functional, keyboard accessible, responsive. No fake metrics; derive from fixtures. Use lucide icons. Do not change others' files.
